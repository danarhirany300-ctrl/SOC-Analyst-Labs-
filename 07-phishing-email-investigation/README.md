# 🛡️ Lab 7 – Phishing Email Investigation

## Objective

Investigate a suspected phishing email by analyzing email headers, sender information, authentication results, URLs, attachments, and indicators of compromise.

## Environment

- Microsoft Defender for Office 365 Learning Lab (or equivalent)
- Microsoft Defender XDR

## Tasks Completed

- Reviewed email metadata
- Analyzed email headers
- Verified SPF, DKIM, and DMARC results
- Investigated embedded URLs
- Reviewed attachment details
- Determined the email verdict
- Documented investigation findings

## Investigation Scenario

Investigated a reported phishing email targeting a finance employee. Reviewed sender information, authentication results, URLs, and attachments to determine whether the message was malicious and recommended appropriate response actions.

## Skills Demonstrated

- Email Security Investigation
- Phishing Analysis
- Header Analysis
- SPF/DKIM/DMARC Validation
- IOC Identification
- Incident Documentation

## Key Takeaway

Effective phishing investigations require validating email authenticity, analyzing embedded content, and identifying indicators of compromise before determining an appropriate response.
